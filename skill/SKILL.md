# Style DNA Skill

Use this workflow when a user provides a reference image and asks to understand or reuse its visual style.

1. Identify the media type.
2. Separate content from style.
3. Extract deterministic facts where possible (dimensions, aspect ratio, palette).
4. Analyze composition, whitespace, color, typography personality, texture, image treatment, hierarchy, and mood.
5. Explain why the design works.
6. Produce negative constraints.
7. Return a compact human-readable Style Brief and structured Style DNA.
8. When asked to apply the style elsewhere, translate the visual rules for the target medium rather than literally copying the original layout or content.

Primary principle: **Extract → Structure → Apply.**
